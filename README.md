# SurpassOne Theme

A flat, minimal color theme for VS Code and Cursor. Designed for daily use with easy-on-the-eyes colors.

![SurpassOne Dark](https://raw.githubusercontent.com/aitit-inc/vscode-surpassone-theme/main/docs/dark-preview.png)
![SurpassOne Light](https://raw.githubusercontent.com/aitit-inc/vscode-surpassone-theme/main/docs/light-preview.png)

## Features

- **Dark & Light** variants included
- **Flat UI** with minimal borders -- uses subtle background differences instead
- **Restrained syntax palette** -- only 4 accent colors + grays to reduce visual noise
- **Warm tones** throughout -- the light theme uses a rosy taupe base, not harsh white

## Color Palette

| Role | Dark | Light |
|------|------|-------|
| Accent (keywords, tags) | `#E8755E` | `#C05248` |
| Strings | `#D4A76A` | `#96702A` |
| Types / Classes | `#6EADB0` | `#2A827E` |
| Numbers / Constants | `#8B9E78` | `#507040` |

## Installation

### VS Code

Search for **"SurpassOne Theme"** in the Extensions panel (`Cmd+Shift+X` / `Ctrl+Shift+X`), or run:

```
ext install surpassone.surpassone-theme
```

### Cursor

Search for **"SurpassOne Theme"** in the Extensions panel.

### Manual Install

Download the `.vsix` file from [GitHub Releases](https://github.com/aitit-inc/vscode-surpassone-theme/releases), then:

- **VS Code**: Extensions panel > `...` > "Install from VSIX..."
- **Cursor**: Extensions panel > `...` > "Install from VSIX..."

## Activating the Theme

1. Open Command Palette (`Cmd+Shift+P` / `Ctrl+Shift+P`)
2. Type **"Color Theme"**
3. Select **SurpassOne Dark** or **SurpassOne Light**
