# SurpassOne Theme for Visual Studio Code

[![Version](https://img.shields.io/visual-studio-marketplace/v/surpassone.surpassone-theme)](https://marketplace.visualstudio.com/items?itemName=surpassone.surpassone-theme)
[![Downloads](https://img.shields.io/visual-studio-marketplace/d/surpassone.surpassone-theme)](https://marketplace.visualstudio.com/items?itemName=surpassone.surpassone-theme)

A flat, monochrome color theme with a single coral accent. Only keywords get color — everything else is expressed through tonal gray hierarchy. Dark and Light variants included.

![Dark](https://raw.githubusercontent.com/aitit-inc/vscode-surpassone-theme/main/docs/dark-preview.png)

![Light](https://raw.githubusercontent.com/aitit-inc/vscode-surpassone-theme/main/docs/light-preview.png)

## Installation

Search for **"SurpassOne Theme"** in the Extensions panel, or run:

```
ext install surpassone.surpassone-theme
```

Also available on [Open VSX](https://open-vsx.org/extension/surpassone/surpassone-theme) for Cursor and other editors.
